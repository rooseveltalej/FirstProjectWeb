# Barcelona Travel Website

This project is a static website for a fictional tourist guide to Barcelona, created as part of an "Introduction to Web Development" course. The site is built using HTML, CSS, and JavaScript, and it is designed to be fully responsive and user-friendly.

## Features

* **Homepage:** A welcoming "hero section" with an attractive slogan and a professional image of the city. It also includes a brief introduction to motivate visitors to explore the rest of the site.
* **History and Culture:** This section provides general information about the city's history, customs, and festivities. It features a list of at least five different festivities with representative images, titles, descriptions, and dates.
* **Tourist Attractions:** A comprehensive list of at least 10 emblematic places, parks, and monuments for visitors to explore. Each attraction includes an image, name, description, schedule, cost, and a link to the official website. An interactive map (not an image) shows the location of each attraction.
* **Gastronomy:** An image gallery showcasing at least five typical dishes and three recommended restaurants. Clicking on a dish opens a modal with its name, description, and main ingredients. Clicking on a restaurant image displays a modal with its name, description, hours, phone number, official website link, and a larger photo. The gallery is organized as a grid with evenly sized and distributed images.
* **How to Get There:** Information on the main airports and transport stations. For each, it provides the name, address, schedules (for stations), a photo, a link to the official website, and a list of services. An interactive map shows the exact location of each airport and station.

## Technical Details

* **Responsive Design:** The website is fully responsive and adapts to different screen sizes, from smartphones to desktop computers, using media queries.
* **CSS Framework:** The project uses [Tailwind CSS](https://tailwindcss.com/) for styling.
* **Separation of Concerns:** HTML, CSS, and JavaScript files are kept separate for better organization and maintenance.
* **No Third-Party Templates:** The HTML structure was created from scratch.

## How to Use

1.  Clone the repository:
    ```bash
    git clone [https://github.com/rooseveltalej/firstprojectweb.git](https://github.com/rooseveltalej/firstprojectweb.git)
    ```
2.  Navigate to the project directory:
    ```bash
    cd firstprojectweb
    ```
3.  Open the `index.html` file in your web browser. This project is configured to run with a Live Server extension on port 5501.

Alternatively, you can deploy the project to a web server that supports Apache HTTP on port 8080.
